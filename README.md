# CONSEQUENCES

MVP 002 — La Oficina.

## Stack
- React + TypeScript + Vite
- localStorage
- No backend / database

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The game separates domain types, engine logic, content, persistence and UI. The current slice focuses on the loop: play → decide → consequence → score → Coins → Shop → replay.
